# AI Website Audit Tool

An AI-powered website audit tool built with **HTML, CSS, and JavaScript**. It analyzes a website using Google PageSpeed Insights and uses Google Gemini AI to generate improvement suggestions.

## Features

* Enter a website URL
* Analyze website performance
* Get SEO score
* Get accessibility score
* Generate AI-powered website improvement suggestions
* Display audit results directly on the webpage

## Technologies

* HTML5
* CSS3
* JavaScript
* Google PageSpeed Insights API
* Google Gemini API
* Fetch API
* Async/Await
* JSON

## How It Works

1. Enter a website URL in the input field.
2. Click the **Analyze** button.
3. The application sends the website URL to the Google PageSpeed Insights API.
4. Performance, SEO, and accessibility scores are retrieved.
5. The audit information is processed using JavaScript.
6. Google Gemini AI analyzes the results and provides recommendations.
7. The results are displayed in the application.
